🚚 Delivery Traky

Delivery Traky is a Flutter application designed to simplify the delivery location selection process and provide live location tracking features.

The app allows users to select their current location or search for another delivery address, retrieve address information from geographic coordinates, and display locations and routes on an interactive map.

✨ Features

📍 Current Location

Allows users to use their current location as the delivery address.
Retrieves the address corresponding to the user's coordinates.

🔎 Address Search

Users can search for another delivery location.
Supports searching for places such as home, office, or other addresses.

🗺️ Interactive Map

Displays locations using an interactive map.
Shows location markers.
Displays routes using polylines.

🌍 Reverse Geocoding

Converts latitude and longitude coordinates into readable address information using OpenStreetMap's Nominatim API.

⏱️ Delivery Estimation

Displays an estimated delivery time of 25–35 minutes on the home screen.
